# Internationalization

A visitor sees translated text, interpolated parameters and correct plural forms, and switching the locale re-renders every translated element in place.

## Sub-features

- `i18n-basic` renders a `t` key in the default locale.
- `i18n-params` interpolates `t-name` into `Hello, {name}!`.
- `i18n-plural` picks `one item` or `{count} items` from `t-count`.
- `i18n-switch` re-renders all keys when `$i18n.locale` changes.
- `i18n-persist` keeps the chosen locale across a reload when `persist: true` (docs site only).

## How to get to it (user POV)

- Open `/e2e/examples/i18n.html` and use the `Set 1`, `Set 5` and `Español` buttons.
- On the docs site, open the language dropdown (button labelled `Select language`) and pick a locale; see [Docs site](./docs-site.md) for the persisted variant.

## Driving it with verify.mjs

Preconditions:

- `doctor --port <port>` exits 0.
- Browser locale `en-US` (the drive's default), so the default locale renders first.

Run `node .claude/skills/verify-nojs/scripts/verify.mjs drive --journey .claude/skills/verify-nojs/journeys/i18n.json`.

- **Default locale.** Step `["goto", "/e2e/examples/i18n.html"]`. `[data-test=welcome-text]` reads `Welcome to our app`, `[data-test=greeting-text]` reads `Hello, Alice!`, `[data-test=plural-text]` reads `one item`.
- **Plural.** Step `["click", "[data-test=set-five]"]`. `[data-test=plural-text]` reads `5 items`.
- **Switch locale.** Step `["click", "[data-test=lang-es]"]`. `[data-test=farewell-text]` reads `Adiós`, the welcome reads `Bienvenido a nuestra app`, the greeting `Hola, Alice!` and the plural keeps its count: `5 elementos`.
- **Proof.** Steps `["screenshot", "01-spanish"]` and `["aria", "01-spanish"]`.

## Gotchas

- The fixture has inline locales and no persistence: a reload returns to English by design. Persistence is proven on the docs site.
- Text is compared after whitespace collapsing; accented characters must match exactly (`Adiós`).
- `e2e/examples/i18n-external.html`, `i18n-detect.html` and `lang-selector.html` cover external locale files, browser detection and a selector; they are not in this journey.
